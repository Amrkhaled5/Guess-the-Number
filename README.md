# 🎯 Guess The Number Game

An interactive and responsive number guessing game built using **HTML**, **CSS**, and **JavaScript**. Players must guess a randomly generated number between 1 and 20 within 10 tries. The game provides visual and text-based feedback, along with a scoring system and a help section for user guidance.

## 🔍 Features

- 🎲 Random number generation (1–20)
- 🧠 Intelligent feedback (too high, too low, correct)
- 🔄 "Play Again" functionality to restart the game
- 📊 Score tracking and best score display
- ❓ Help popup modal with instructions
- ✨ Smooth UI transitions and animations
- 🧼 Responsive design and clean layout

## 🛠️ Technologies Used

- **HTML** – Structure and layout  
- **CSS** – Styling, positioning, and animations  
- **JavaScript** – Logic, DOM manipulation, event handling

## 🚀 How To Play

1. Choose a number between **1 and 20**.
2. You have **10 chances** to guess the correct number.
3. If you guess correctly, you win and your score is recorded.
4. If not, you'll receive a hint (too high or too low).
5. If you run out of guesses, the game ends and reveals the correct number.
6. Use the **"Play Again"** button to reset the game anytime.
7. Click the **"Help ?"** button for instructions.

## 📦 Setup & Usage

To run the project locally:

1. Clone or download the repository.
2. Make sure all files (`index.html`, `stylee.css`, `script.js`) are in the same folder.
3. Open `index.html` in your browser.

No additional installation or dependencies required.
